# 🚀 Selected Work

### 🧠 PyDeps — Intelligent Python Dependency Engineering

A Python dependency scanner and project bootstrapper designed to automate the annoying parts of dependency management.

It can analyze imports, resolve packages, install dependencies, perform security audits, detect outdated packages and generate reproducible project artifacts.

**Python · AST · Typer · Rich · pip-audit · Docker · pytest**

> Turning `pip install ...` into an actual dependency workflow.

---

### 🎙️ Alice — Local Voice Interface for Kilo

A local voice layer designed to turn **Kilo Code into a voice-driven development assistant**.

Alice handles the parts that normally make voice assistants frustrating:

* 🎤 microphone capture
* 📝 streaming speech-to-text
* 🔊 text-to-speech
* 👂 voice activity detection
* 🗣️ wake-word detection
* ⚡ barge-in / interruption
* 🔇 echo suppression
* 🔌 provider abstraction
* 🧠 Kilo session integration

**Python · STT · TTS · VAD · Audio DSP · Kilo**

> The goal isn't another chatbot with a microphone.
> It's a computer interface that you can actually talk to.

---

### 💬 BlueChat — Rethinking Social Communication

A messaging/social platform experiment exploring the boundary between:

**private communication ↔ public discovery**

The project evolved beyond a simple chat application toward concepts such as contextual profiles, public-to-private interaction, social graphs and richer forms of communication.

**React · TypeScript · Supabase · Real-time systems**

> What happens when messaging stops being just an inbox?

---

### 🖥️ SkyOS — A Web-Based Operating System Experiment

A cloud-first operating system concept built around a web interface.

The project explores:

* virtualized desktop experiences
* modular applications
* cloud integration
* extensibility
* authentication
* system-like UX inside the browser

**JavaScript · React · Node.js**

> An OS doesn't necessarily need to start with a kernel.

**TypeScript · React · Vite · Tailwind · Supabase**

# 🧪 My GitHub Philosophy

I don't want my repositories to be a collection of tutorials that happen to compile.

I prefer projects that answer a question.

Sometimes the question is:

> **Can this be automated?**

Sometimes:

> **Can software understand this?**

Sometimes:

> **Can this interface feel completely different?**

And occasionally:

> **What happens if we push this idea way too far?**

Those experiments are often where the interesting engineering starts.
